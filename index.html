EmailJS — Envio de E-mail

Envia e-mails reais diretamente do navegador, sem backend. Gratuito até 200/mês.

Não configurado
📋 Como configurar (5 minutos): 1. Acesse emailjs.com e crie uma conta gratuita
2. Em Email Services, conecte seu Gmail ou outro provedor → copie o Service ID
3. Em Email Templates, crie um template com as variáveis: {{to_email}}, {{to_name}}, {{message}}, {{subject}} → copie o Template ID
4. Em Account → API Keys, copie sua Public Key
5. Cole as três chaves abaixo e salve
💬

Z-API — WhatsApp

Envia mensagens via WhatsApp conectando seu número. Plano de teste gratuito disponível.

Não configurado
📋 Como configurar (10 minutos): 1. Acesse app.z-api.io e crie uma conta
2. Crie uma nova instância e escaneie o QR Code com seu WhatsApp
3. No painel da instância, copie o Instance ID e o Token (só o código, sem URLs)
4. Cole abaixo e salve — pronto para enviar mensagens reais!
⚠️ Atenção: use um número de WhatsApp exclusivo para a plataforma (não seu pessoal) para evitar banimentos.
